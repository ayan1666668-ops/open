# Swarm dynamics consolidation

The mixed-phase controller can retain evidence without turning memory into authority.

Memory progresses from observation to retained trace, correlated pattern, candidate belief, and finally
a supported memory crystal. Contradictions prevent crystallization. Repeated copies of one source do
not substitute for independent confirmation.

Narrative context may be compacted only when the underlying evidence references and unresolved
obligations remain available.

## Shadow evaluation

Changes to dynamics profiles, allocation thresholds, or population policy can be evaluated in shadow
mode against retained observations and bounded experiments.

A shadow result is always `proposal-only`. It cannot replace the live policy, grant tools, change
credentials, weaken sandboxing, skip approval, or authorize its own adoption.

## Diagnostics

Operator diagnostics should surface:
- phase coexistence
- active replica count
- candidate entropy
- evidence completeness
- resource/context/debt pressure
- unresolved critical disagreement
- unknown classifications

Unknown telemetry stays unknown rather than being treated as independent evidence or safe state.
